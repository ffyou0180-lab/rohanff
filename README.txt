# GameHub BD
একটি simple Game + Video website demo.

ব্যবহার:
1. index.html ফাইলটি Chrome-এ খুলুন।
2. `＋ Add Game` চাপুন।
3. Game name, image URL, video URL, download URL ও description দিন।
4. Save Game চাপলে browser-এর localStorage-এ data থাকবে।

নোট:
এটি frontend-only demo। সত্যিকারের online admin panel, database এবং server-side file/video upload করতে hosting + backend/database লাগবে।
